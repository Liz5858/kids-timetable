# 우리 아이 시간표

초등학생 자녀의 요일별 시간표를 모바일에서 보기 좋게 만든 웹앱입니다.

- **실제로 사용하는 웹앱 링크(추가/수정/삭제 가능)**: 이 저장소의 `timetable.html`은 소스 코드 백업용입니다. 일정 추가·수정·삭제 기능은 Claude Artifact 런타임(`window.claude`)에 의존하기 때문에, GitHub Pages 등 일반 웹 호스팅에서는 그 기능이 동작하지 않습니다.
- 실제로 매일 보고 수정하는 링크는 Claude 대화에서 공유된 Artifact 링크를 사용해 주세요.

## 구성

- `timetable.html` — 단일 파일 웹앱 (HTML/CSS/JS). 요일별 보기, 주간 한눈에 보기, 일정 추가/수정/삭제 팝업 포함.
